Smart Resource Allocation using Deep Reinforcement Learning

Project Overview

This project addresses the Adaptive Knapsack Problem in cloud computing resource allocation. It compares three different approaches:



Greedy Algorithm: Heuristic-based decision making.



Deep Q-Network (DQN): An AI agent trained to optimize rewards over time.



Dynamic Programming (DP): The theoretical optimal solution (Oracle).



How to Run

Install Dependencies:



Bash

pip install -r requirements.txt

Train the AI Agent:



Bash

python src/train.py

Run Comparison \& Evaluation:



Bash

python src/compare.py

Results

The results, including learning curves and performance comparisons, are automatically saved in the /plots directory.
